# Mot : Définition

Novelty detection : le mécanisme par lequel un organisme intelligent est capable d'identifier un modèle sensoriel entrant comme étant jusqu'ici inconnu.

fuzzing : technique pour tester des logiciels. Injection de données aléatoires dans entrées d’un programme. src : Wikipedia [https://en.wikipedia.org/wiki/Fuzzing](https://en.wikipedia.org/wiki/Fuzzing)

ransomware : logiciel malveillant qui prend en otage des donnée personnelles en les chiffrant et les rend en échange (le plus souvent) d’argent. src : Wikipedia [https://fr.wikipedia.org/wiki/Rançongiciel](https://fr.wikipedia.org/wiki/Ran%C3%A7ongiciel)

cryptologie : science englobant la [cryptographie](https://fr.wikipedia.org/wiki/Cryptographie) – l'écriture secrète – et la [cryptanalyse](https://fr.wikipedia.org/wiki/Cryptanalyse) – l'analyse de cette dernière.

CTF : jeu consistant à exploiter des vunérabilité affectant des logiciels de manière à s’introduire sur un ordinateur pour récupérer les drapeaux, preuves de l’intrusion.

Pytorch : open source machine-learning library based on the Torch library, used for applications such as computer vision, deep learning research, and nlp, originaly developped by Meta AI and now part of the Linux Fondation umbrella. Tesla Autopilot is built on it. scr : Wikipedia [https://en.wikipedia.org/wiki/PyTorch](https://en.wikipedia.org/wiki/PyTorch) 

Escalade de privilèges (*Privilege escalation - JailBreaking)* : acte d'exploiter un bug, une faille de conception ou une surveillance de configuration dans un système d'exploitation ou une application logicielle pour obtenir un accès élevé à des ressources normalement protégées d'une application ou d'un utilisateur. 

- Escalade verticale  *(privilege elevation)* : utilisateur ou une application de privilège inférieur accède à des fonctions ou à un contenu réservé aux utilisateurs ou aux applications de privilèges supérieurs
- Escalade horizontale : un utilisateur normal accède à des fonctions ou à du contenu réservé à d'autres utilisateurs normaux

src Wikipedia : [https://en.wikipedia.org/wiki/Privilege_escalation#Jailbreaking](https://en.wikipedia.org/wiki/Privilege_escalation#Jailbreaking)

vibe coding : technique de programmation utilisant l'IA avec laquelle une personne décrit à un grand modèle de langage (LLM) étant capable d'écrire du code, un problème en quelques phrases sous la forme d'une invite. Le LLM génère alors des logiciels, transformant ainsi le rôle du programmeur : guidage de l'IA, test du code source généré par l'IA et affinement de celui-ci, remplaçant ainsi l'écriture manuelle de code.

src : [Wikipedia Vibe_coding](https://fr.wikipedia.org/wiki/Vibe_coding)

halucinations : désigne un phénomène où un modèle d’IA (comme ChatGPT, par exemple) produit une réponse fausse, inventée ou trompeuse, tout en paraissant convaincant et cohérent.

src : chatGPT

backdoor (porte dérobée) : Une backdoor est un accès secret intégré intentionnellement ou installé à la suite d’une attaque. Elle permet de contourner les protections d’un système informatique (mots de passe, pare-feu, antivirus, etc.). (Beaucoup de détails sur la page Wikipédia)

src https://en.wikipedia.org/wiki/Backdoor_(computing)# + ChatGPt

Cyber kill chain : A cyber kill chain is the process by which perpetrators carry out cyberattacks. It reveals the phases of a cyberattack: from early reconnaissance to the goal of data exfiltration. The kill chain can also be used as a management tool to help continuously improve network defense.

fine-tunning :Technique consistant à spécialiser un modèle d’IA pré-entraîné à l’accomplissement d’une tâche spécifique. Cette pratique est parfois traduite par « affinage », « réglage fin », « peaufinage » ou encore « spécialisation ». scr : [CNIL](https://www.cnil.fr/fr/definition/ajustement-fine-tuning)

IA agentique : Systèmes dans lesquels des agents émettent des commandes pour interagir avec leur environnement afin de résoudre les tâches qui leur sont assignées, souvent de manière autonome. 

Retrieval-Augmented Generation (RAG) : the process of optimizing the output of a large language model, so it references an authoritative knowledge base outside of its training data sources before generating a response.

KDDCUP99 : base de données utilisée pour simuler quatres types d’attaques sur un réseau.

- DOS : déni de service, par exemple inondation SYN ;
- R2L : accès non autorisé depuis une machine distante, par exemple en devinant le mot de passe ;
- U2R : accès non autorisé aux privilèges de superutilisateur local (root), par exemple, diverses attaques de « dépassement de tampon » ;
- sondages : surveillance et autres sondages, par exemple, analyse des ports.
